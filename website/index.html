Capabilities

Not Just Prompts.
An Agentic System.

Shared session state, adversarial deliberation, multi-file CSV retrieval, self-evolution, chunked execution on free models.

CHUNK

Chunked Execution

A frontier planner breaks your task into small chunks. Each chunk runs on the cheapest capable model — local Ollama, free cloud APIs, or your paid keys. Outputs synthesized into a final verdict.

DEBATE

Adversarial Deliberation

Personas don't echo each other. They debate with low satisfaction defaults, raise objections grounded in real task context, and escalate to Raj only when deadlocked.

EVOLVE

Self-Evolving Team

Every accepted run extracts lessons. Confirmed outcomes feed patch proposals — prompt edits, CSV reference rows, router changes. Devi asks after every run if the team is ready.

REFS

28 CSV Reference Files

Colors, styles, typography, UX guidelines, chart types, landing patterns, 16 stack guides. Personas retrieve 3-5 files per chunk via a shared LLM ranker — same cost, 5x coverage.

VAULT

Obsidian Vault + KB

Kavi scans your repo, builds an Obsidian-compatible vault, enriches notes with an LLM, and syncs a per-persona knowledge bank. Personas read your project context first.

DEVI

No API Keys Needed

The host LLM voices each persona from a prompt queue. No paid API calls. Or plug in keys for Anthropic, OpenAI, Google, Groq, Together, OpenRouter, DeepSeek, or local Ollama.

Getting Started

From Install to
Evolved Team

Five steps to automated UX critique in your IDE.

01

Install

npm install -g analyzthis_design then npx analyzthis_design --target all

02

Collect Knowledge

npx analyzthis_design collect — Kavi scans your repo, builds a vault, syncs the knowledge bank.

03

Run a Critique

npx analyzthis_design run --task "Review onboarding" — or invoke /persona-orchestrator in your IDE.

04

Accept & Confirm

session accept --persona arjun and outcome --confirm --persona arjun --result shipped

05

Evolve

evolve --extract proposes patches. evolve --apply writes them. Devi asks after every run if the team is ready.

Auditable

Plain Source.
Consent-Based.

No obfuscation. No auto-install. No hidden behavior. Every file is readable source.

Plain Source

Every JS file in dist/ is readable, unobfuscated, unminified. No javascript-obfuscator dependency. Security tools can review every line.

No Auto-Install

postinstall only prints a message. Skill installation requires explicit npx analyzthis_design --target <ide>. No filesystem mutation without consent.

No Network Calls

Zero network requests on install. No telemetry, no exfiltration, no phone-home. API keys only used when you explicitly run a critique.

CSV Validation

npm run validate checks all 28 CSV files against schema.json — row integrity, header match, cross-file joins, filter column population.
