What Makes It Different

Not just another prompt library. A full agentic system with shared state, adversarial deliberation, and self-evolution.

[chunk]

Chunked Execution

A frontier planner breaks your task into small chunks. Each chunk runs on the cheapest capable model — local Ollama, free cloud APIs, or your paid keys. Outputs are synthesized into a final verdict.

[debate]

Adversarial Deliberation

Personas don't echo each other. They debate with low satisfaction defaults, raise objections grounded in real task context, and escalate to Raj only when deadlocked.

[evolve]

Self-Evolving Team

Every accepted run extracts lessons. Confirmed outcomes feed patch proposals — prompt edits, CSV reference rows, router changes. Dry-run by default, human review before apply.

[refs]

28 CSV Reference Files

Colors, styles, typography, UX guidelines, chart types, landing patterns, 16 stack guides. Personas retrieve 3-5 files per chunk via a shared LLM ranker — same cost, 5x coverage.

[vault]

Obsidian Vault + Knowledge Bank

Kavi scans your repo, builds an Obsidian-compatible vault, enriches notes with an LLM, and syncs a per-persona knowledge bank. Personas read your project context first.

[devi]

Devi — No API Keys Needed

The host LLM (Cursor, Claude, etc.) voices each persona from a prompt queue. No paid API calls. Or plug in keys for automated runs with Anthropic, OpenAI, Google, Groq, and more.

How It Works

From install to evolved team in five steps.

01

Install

npm install -g analyzthis_design then npx analyzthis_design --target all

02

Collect Knowledge

npx analyzthis_design collect — Kavi scans your repo, builds a vault, syncs the knowledge bank.

03

Run a Critique

npx analyzthis_design run --task "Review onboarding" — Frontier planner chunks the task, cheap models execute, synthesis produces a verdict.

04

Accept & Confirm

session accept --persona arjun and outcome --confirm --persona arjun --result shipped

05

Evolve

evolve --extract proposes patches. evolve --apply writes them. Devi asks after every run if the team is ready to evolve.

Auditable & Consent-Based

No obfuscation. No auto-install. No hidden behavior. Every file is plain source.

[check]

Plain Source

Every JS file in dist/ is readable, unobfuscated, unminified. No javascript-obfuscator dependency. Security tools can review every line.

[check]

No Auto-Install

postinstall only prints a message. Skill installation requires an explicit npx analyzthis_design --target <ide> command. No filesystem mutation without consent.

[check]

No Network Calls

The package makes zero network requests on install. No telemetry, no exfiltration, no phone-home. API keys are only used when you explicitly run a critique.

[check]

CSV Validation

npm run validate checks all 28 CSV files against schema.json — row integrity, header match, cross-file joins, filter column population.
