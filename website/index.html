Each persona has a distinct lens, a curated skill, and a short system card. They deliberate adversarially — not in parallel echo chambers. Every critique grounds in your design system tokens and project context.

Capabilities

Not Just Prompts. An Agentic System.

Shared session state, adversarial deliberation, multi-file CSV retrieval, self-evolution, chunked execution on free models. Built for production design workflows.

⚙

Chunked Execution (v2.0)

A frontier planner breaks your task into small chunks. Each chunk runs on the cheapest capable model — local Ollama, free cloud APIs (Groq, Gemini, OpenRouter), or your paid keys. Outputs synthesized into a final verdict.

⚘

Adversarial Deliberation

Personas don't echo each other. They debate with low satisfaction defaults, raise objections grounded in real task context, and escalate to Raj only when deadlocked. Each round requires new evidence.

📜

Self-Evolving Team

Every accepted run extracts lessons. Confirmed outcomes feed patch proposals — prompt edits, CSV reference rows, router changes. Devi asks after every run if the team is ready to evolve. Dry-run by default.

📊

28 CSV Reference Files

Colors, styles, typography, UX guidelines, chart types, landing patterns, 16 stack-specific guides. Personas retrieve 3-5 files per chunk via a shared LLM ranker — same cost, 5x coverage.

📚

Obsidian Vault + Knowledge Bank

Kavi scans your repo, builds an Obsidian-compatible vault, enriches notes with an LLM, and syncs a per-persona knowledge bank. Personas read your project context first — PRDs, brand tokens, components.

🤖

Devi — No API Keys Needed

The host LLM voices each persona from a prompt queue. No paid API calls. Or plug in keys for automated runs with Anthropic, OpenAI, Google, Groq, Together, OpenRouter, DeepSeek, or local Ollama.

The UX Ideator workflow runs 7 personas across 6 phases to produce a single, deliberated, implementation-ready IA design. Each phase has a clear owner and output format.

Getting Started

From Install to Evolved Team

Five steps to automated UX critique in your IDE.

01

Install

npm install -g analyzthis_design then npx analyzthis_design --target all

02

Collect Knowledge

npx analyzthis_design collect — Kavi scans your repo, builds a vault, syncs the knowledge bank.

03

Run a Critique

npx analyzthis_design run --task "Review onboarding" — or invoke /persona-orchestrator in your IDE.

04

Accept & Confirm

session accept --persona arjun and outcome --confirm --persona arjun --result shipped

05

Evolve

evolve --extract proposes patches. evolve --apply writes them. Devi asks after every run if the team is ready.
